# Everyone's Favorite Place (EFP)

マルチサーバーの参加者が、自分の拠点や設備の座標を登録し、公開設定に応じて全員で共有できるPaperプラグインです。

## 対応バージョン

- Minecraft: 26.2
- Paper API: 26.2.build.+
- 必要環境: Java 25

## 機能

- 拠点(座標)の登録・削除・名前変更
- 公開/非公開の切り替え(デフォルトは公開)
- ディメンション(オーバーワールド/ネザー/エンド)ごとに座標を記録・自動判別
- 公開されている拠点を、座標に応じたグリッド配置のGUI(チェスト画面)で一覧表示
- GUI中央には常に原点(X:0 Z:0)を示すコンパスを固定表示、北が上になるよう配置
- 登録者の顔アイコン(プレイヤーヘッド)とユーザー名をGUI上に表示
- データはサーバー内の`locations.yml`に保存され、再起動後も保持

## コマンド

| コマンド | 説明 |
|---|---|
| `/efp add <拠点名> [public\|private]` | 現在地を拠点として登録(省略時は公開、ディメンションは自動記録) |
| `/efp remove <拠点名>` | 自分の拠点を削除 |
| `/efp rename <旧名> <新名>` | 拠点名を変更 |
| `/efp list` | 自分の拠点一覧を表示 |
| `/efp public <拠点名>` | 拠点を公開に設定 |
| `/efp private <拠点名>` | 拠点を非公開に設定 |
| `/efp gui` | 今いるディメンションの公開拠点を座標マップGUIで表示 |

詳しい使い方は [使用説明書](使用説明書.md) を参照してください。

## 導入方法

1. [Releases](../../releases) から対応するMinecraftバージョンのjarファイルをダウンロード
2. サーバーの`plugins`フォルダに配置
3. サーバーを再起動

参加者側への追加導入は不要です(通常のチェストGUIのみを使用)。

## ビルド方法

```
git clone https://github.com/SHUN-CHACHA/efp.git
cd efp
./gradlew build
```

生成された`build/libs/efp-<バージョン>.jar`を使用してください。
