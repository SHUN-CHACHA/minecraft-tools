# Everyone's Favorite Place 使用説明書

## これは何？

サーバー内の自分の拠点や設備の座標を登録し、公開に設定すれば他の参加者にも共有できるプラグインです。逆に非公開にしておけば、自分だけのメモとして使えます。

## 基本の使い方

### 1. 拠点を登録する

登録したい場所に立って、以下のコマンドを実行します。

```
/efp add ホーム
```

「ホーム」という名前で、今いる座標が**公開**として登録されます。

非公開にしたい場合は、末尾に`private`を付けます。

```
/efp add 資材庫 private
```

※ 同じ名前で再度`/efp add`を実行すると、その拠点の座標が上書きされます(引っ越しに便利です)。

### 2. 自分の拠点一覧を見る

```
/efp list
```

登録済みの拠点が、名前・ディメンション・座標・公開状態つきで表示されます。

### 3. 公開/非公開を後から変更する

```
/efp public 資材庫
/efp private ホーム
```

### 4. 拠点の名前を変える

```
/efp rename ホーム 新居
```

### 5. 拠点を削除する

```
/efp remove 資材庫
```

### 6. みんなの拠点を地図で見る

```
/efp gui
```

チェスト画面が開き、公開されている拠点が、実際の座標の位置関係に応じてマス目上に並びます。

- **上が北、下が南、右が東、左が西**
- 画面中央のコンパスが、座標(X:0, Z:0)の原点を示します
- 拠点のアイコンはその人の顔(プレイヤーヘッド)で、名前・座標がアイテムの説明欄に表示されます
- クリックすると、その場所の詳細がチャットに表示されます
- **今自分がいるディメンション(オーバーワールド/ネザー/エンド)の拠点だけ**が表示されます。別のディメンションの拠点を見たい場合は、そのディメンションに移動してから`/efp gui`を実行してください

## よくある質問

**Q. 拠点が多すぎてマス目に収まりきりません**
A. 一番遠い拠点に合わせて自動的に縮尺(1マスあたりの距離)が調整されるので、表示しきれなくなることはありません。ただし拠点同士が近いと、同じマスにまとめて表示されることがあります。その場合はそのマスをクリックすると、まとまっている拠点すべての詳細が表示されます。

**Q. 他人の拠点を削除・変更できますか？**
A. できません。`remove`・`rename`・`public`・`private`は、自分が登録した拠点にしか使えません。

**Q. サーバーを再起動したらデータは消えますか？**
A. 消えません。登録した拠点はサーバー内の`plugins/EveryonesFavoritePlace/locations.yml`に保存されます。

## コマンド一覧(まとめ)

| コマンド | 説明 |
|---|---|
| `/efp add <拠点名> [public\|private]` | 現在地を登録(省略時は公開) |
| `/efp remove <拠点名>` | 削除 |
| `/efp rename <旧名> <新名>` | 名前変更 |
| `/efp list` | 自分の拠点一覧 |
| `/efp public <拠点名>` | 公開にする |
| `/efp private <拠点名>` | 非公開にする |
| `/efp gui` | 座標マップGUIを開く |
