# MaLiLib IME 使用説明書

## MaLiLib IME とは

MaLiLib IME は、**Litematica・MiniHUD・Tweakeroo などの MaLiLib 系 MOD の入力欄で、日本語入力(IME)を使えるようにするアドオン MOD** です。

Minecraft 26.1 以降、バニラ(チャット欄など)では日本語入力に標準対応しました。しかし、MaLiLib 系 MOD の画面では、この仕組みがうまく働きません。そのため、次のような状態になっていました。

- 入力欄をクリックしても、日本語モードに切り替わらない
- 日本語モードにはなるが、変換中の文字が表示されず、確定するまで何を打っているか分からない

MaLiLib IME を入れると、MaLiLib 系 MOD の入力欄でも、チャット欄と同じように日本語を入力できるようになります。

このMODは単体では何もしません。**Litematica などの MaLiLib 系 MOD と一緒に入れて使う「アドオン」** です。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| Minecraft | 26.2 / 26.3(1つの jar で両方に対応) |
| MOD ローダー | Fabric Loader 0.18.0 以上 |
| 前提 MOD | MaLiLib(と、Litematica などの MaLiLib 系 MOD) |
| Fabric API | 不要 |
| 導入場所 | クライアント(自分の PC)のみ。サーバーへの導入は不要です |
| 動作確認済み(26.3) | Windows / Litematica 0.29.0・MaLiLib 0.30.1・MiniHUD 0.41.1 |
| 動作確認済み(26.2) | Windows / Litematica 0.28.7・MaLiLib 0.29.6・MiniHUD 0.40.7 |

## ダウンロード

1. [GitHub Releases](https://github.com/SHUN-CHACHA/minecraft-tools/releases) を開きます。
2. 「MaLiLib IME」のリリースを探し、`malilibime-(バージョン).jar` をダウンロードします。

## 導入方法

ダウンロードした jar ファイルを、**Litematica や MaLiLib の jar が入っているのと同じ `mods` フォルダ** に置いてください。

### Prism Launcher の場合

1. 使っているインスタンスを選び、「編集」を開きます。
2. 左側の「MOD」を選びます。
3. ダウンロードした jar ファイルを、MOD 一覧にドラッグ&ドロップします。

「フォルダを開く」から `minecraft\mods` フォルダを開いて、直接コピーしても大丈夫です。

### 公式ランチャーの場合

1. Windows のエクスプローラーのアドレス欄に `%appdata%\.minecraft\mods` と入力して開きます。
2. ダウンロードした jar ファイルを、そのフォルダにコピーします。

### 導入できたかの確認

Mod Menu を入れている場合は、タイトル画面の「MOD」一覧に「MaLiLib IME」が表示されていれば導入できています。

## 使い方

**特別な設定や操作は必要ありません。** 導入するだけで有効になります。

1. Litematica などの画面で、入力欄をクリックします(図面の保存画面のように、最初から入力欄が選ばれている画面もあります)。
2. 「半角/全角」キーで日本語モードに切り替えて、文字を入力します。
3. 変換中の文字は、入力欄のすぐ下に緑の枠で表示されます。変換候補は Windows の IME のウィンドウに表示されます。
4. Enter で確定すると、入力欄に文字が入ります。

使える画面の例です。

- Litematica:図面の保存画面、領域エディタの名前欄、各種設定画面
- MiniHUD / Tweakeroo:設定画面の入力欄

## よくある質問

### 日本語が入力できない・変換中の文字が表示されない

次の点を確認してください。

- MaLiLib IME の jar が、MaLiLib と同じ `mods` フォルダに入っているか
- Minecraft のバージョンが 26.2 または 26.3 か
- CocoaInput や IMBlocker など、ほかの日本語入力系 MOD を一緒に入れていないか(併用は動作未確認です)

### バニラのチャット欄や看板に影響はありますか?

ありません。MaLiLib IME が手を加えるのは MaLiLib 系 MOD の入力欄だけで、バニラの入力欄の動作は変えていません。

### サーバーに入れる必要はありますか?

ありません。自分の PC(クライアント)に入れるだけで使えます。

### Mac や Linux でも使えますか?

動作確認は Windows のみです。Mac はバニラ側が IME に対応していますが、このMODでの動作は未確認です。Linux はバニラ側の IME 表示が現時点で未対応のため、効果がありません。

## 更新方法

`mods` フォルダにある古い `malilibime-(バージョン).jar` を削除してから、新しい jar を入れてください。古い jar と新しい jar を両方入れたままにしないよう注意してください。

## 削除方法

`mods` フォルダから `malilibime-(バージョン).jar` を削除するだけです。設定ファイルなどは作らないので、ほかに消すものはありません。
